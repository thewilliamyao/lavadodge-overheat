# LavaDodge-Overheat
Playing around with HTML5 Game Development

## Demo:
https://thewilliamyao.github.io/lavadodge-overheat/

## Features:
If the floor is cracking up, deadly lava will soon consume that square! Use your keyboard's arrow keys to protect Olaf!


## iPhone remake (2026)
Play it on iPhone: https://thewilliamyao.github.io/lavadodge-overheat/ios/ (open in Safari, then Share > Add to Home Screen). Source and details are in [`ios/`](ios/).

## 3D version (2026)
Play the 3D version: https://thewilliamyao.github.io/lavadodge-overheat/3d/ (Safari, then Share > Add to Home Screen). Source and details are in [`3d/`](3d/).

Both versions support 2 players, on the same phone or online with a room code.
